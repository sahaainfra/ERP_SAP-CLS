# Discovery note 04.09

Inspected (searched: alert, alr_alerts, alr_rule_runs, alr_rules, automation, engine, rules): no `alr_*` table existed. What did: the event bus and outbox with consumers (01.04) and the job scheduler (01.04); the notification engine with `notify()` and the `alerts` category (04.06); the task service (04.08); the communication gateway's channels (04.07); the integration hub for webhooks (01.08); the workflow engine for approvals (04.01); the escalation of approval tasks (04.02), which stays where it is. Nothing let an administrator say "tell the project manager when a guarantee is within 45 days of expiry".
