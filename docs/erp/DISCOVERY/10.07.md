# Discovery 10.07: GIS, site maps and location intelligence

Inspected: the location breakdown of 10.03 (`proj_locations` already has `lat`, `lng`, `chainage_from`, `chainage_to`), the organisation sites with geofences (`org_sites`: latitude, longitude, circle or polygon), the attendance punches (`att_punches` with positions), the workflow engine and resolvers, the parameter registry, the content security policy settings (02.07), the list and export services, the page tracker and navigation seeds. No map library, no `gis_*` table and no GeoJSON or KML code existed. Progress (14.05), DPR (14.02), NCR/incident records and equipment are not live yet.
