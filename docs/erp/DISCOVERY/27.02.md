# Part 27.02 — Self-Service Report Builder & Semantic Layer

Part 27.01 is in progress. The local development database has no G1 or G2 sign-off records. The initial run implemented a thin adapter under §0.4. The user subsequently authorised development behind the disabled flags while the acceptance gates remain pending. The follow-up now provides a Project Status report builder. See the [completion record](../COMPLETION/27.02.md) for current capability and evidence. The global standards, role catalogue and workflow reference are in `docs/erp/`. The referenced master UI v3 and mobile standard and the P001–P166 verification report were unavailable in the workspace.

| Requirement | Existing implementation | Decision |
|---|---|---|
| FR-01 Semantic datasets | Part 27.01 exposes internal project status data through Project Setup. Other modules own queries for procurement, stock, labour, progress, billing and finance. | Reuse the project status reader for a single dataset with a fixed field list. Versioned definitions, joins and measures await the registry. |
| FR-02 Report Builder, personal and shared reports | List Reports use `ui_saved_views` for current list settings. Forms and dashboard widgets have their own shared services. | Reuse List Reports for preview, persistence, sharing and export. Schedule owned saved reports through Part 27.01. Pivots and dashboard publishing remain under D-767. |
| FR-03 Query safety | Part 27.01 uses the List Report validator and a paginated owner query. `platform/list` binds filter values and checks defined columns. | Reuse pagination and the lifecycle-state filter. Validate field selections before calling the owner. Query timeouts and read-replica execution await the general runner. |
| FR-04 Dataset versions | Shared change requests and the workflow engine support controlled configuration changes. | New dataset versions and approval hook after prerequisites. |
| BR-01 Masked field selection | The project-status reader publishes a small non-commercial field set. Payroll governs salary through `pay.salary.view`. | Restrict this dataset to known project-status fields. The adapter rejects salary requests. A governed payroll dataset and salary measure await the full builder. |
| §5 Storage | The development database has `proj_projects`, `ui_saved_views`, `ui_widgets`, `ui_dashboards`, `ui_export_jobs` and `core_schedules`. It has no BI dataset or custom-report tables. | Add a reversible flag seed. Business schema and high-volume query plans await dataset and report design. |
| §6 Services and API | Part 27.01 provides `readProjectStatusReport`. Jobs, exports, audits and outbox services are shared. | Reuse the owner report in an internal read adapter. Builder and dataset APIs and OpenAPI await their workflows. |
| §7 Reports, builder and designer | The app shell, List Report, form wizard and widget platform exist. The design registry contains a Report Builder icon. | Reuse those components when the three Part 27.02 pages are implemented. |
| §7A UI v3 and phone | Project Setup and List Report have desktop and mobile Playwright cases. | Reuse those tests as owner evidence. Part 27.02 screenshots and accessibility checks require its pages. |
| §8 Roles and data access | Project Setup enforces `proj.project.view` and company and project scope. IAM distinguishes site grants. | Reuse source permission and scoped rows. Power-user and SYSADM dataset administration await the builder. |
| §9 Maker-checker | `core_change_requests` and the shared approval engine own configuration approval and audit. | Reuse for dataset configuration. The adapter uses no writes. |
| §10 Dashboards and exports | (03.07) owns widgets and dashboards. Part 03.03 owns list CSV/XLSX/PDF exports. | Reuse export and dashboard services when custom reports have approved definitions and scopes. |
| §11 Integrations | Report output from Part 27.01 includes the source project ID, and the widget registry provides trusted providers. | Reuse the source report. Report/widget publishing to Part 03.07 and data for Part 27.03 await the full builder. |
