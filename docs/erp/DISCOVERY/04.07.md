# Discovery note 04.07

Inspected (searched: communication, gateway, comm_, otp, consent, dlt, whatsapp, sms, sendgrid, webhook, reply): no `comm_*` table existed. What did: the integration hub (01.08) with its connector registry, rate limit, circuit breaker, retries, `email`/`sms`/`whatsapp` connector types (sandbox and generic HTTP providers only), signed inbound webhooks (`/api/v1/core/webhooks/:connector`, event `core.webhook.received`); the notification engine (04.06) with `gateways.register` and default gateways that called the connectors directly; the sign-in policy's notify connectors and the code sent by MFA (02.01); the push sender (web push subscriptions). Nothing kept a consent, checked a DLT template, tried a second connector, or linked a reply to a record.
