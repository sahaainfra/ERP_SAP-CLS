# Discovery note 03.01

Inspected: `src/client/design-tokens.css` was a copy of the prompt pack's reference stylesheet (its header said "generated from design-tokens.json", but neither the JSON nor a generator was in the repository); three themes worked through `<html data-theme>`, chosen in the shell's theme menu and kept in the browser, and since 02.03 also saved in the profile (`iam_user_profiles.preferences_json.theme`) and re-applied by a `ThemeSync` component; density variables existed (compact, cozy, touch) but nothing set them and the stylesheet did not use them; the font stacks named IBM Plex, but no font was installed, so system fonts were used; there was no icon set, no `<Icon>`, no style guide, no contrast check and no rule against hard-coded colours (searched: design, tokens, themes, typography, iconography, ui_user_preferences, density, lucide, plex, tailwind). Two colour values were in `styles.css` (the dialog backdrop and the QR background). There is no `ui` module and no Tailwind. Part 01.01 is accepted.
