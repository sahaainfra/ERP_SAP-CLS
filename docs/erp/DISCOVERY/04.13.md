# Discovery note 04.13

Inspected (searched: engine, excel, export, import, xl_job_errors, xl_jobs, xl_templates, xlsx, bulk): no `xl_*` table existed. What did: the single-sheet XLSX, CSV and PDF writers with formula neutralisation (03.03, `platform/export`); the list registry and the export service of the UI module (private to it, with its own guard); the XLSX reader (`read-excel-file`) used by the document bulk upload (04.10) and the IAM user import (02.03); the sample document import of the workflow engine (04.01/04.04) as a transactional example; the organisation service for masters (02.02); the file service types and virus scanner (01.05); the job runner (01.04); the maker-checker pattern of configuration (04.10 to 04.12); notifications (04.06). Prerequisites 03.03 and 04.01 are accepted. The existing one-off imports (documents, users, sample documents) are left as they are; new imports register with this engine.
