# Discovery note 01.03

Inspected: after part 01.02 the repository had feature flags, audit log, outbox, idempotency, integrity checks, company-scope helpers and the shell with four admin pages. Search terms (company, settings, financial year, period, numbering, series, sequence, holiday, parameter, approval, GSTIN, PAN) found no table, route, page or service for any of them; the only hits were the `company_id` scope column, the role catalogue (`docs/erp/06_ROLE_CATALOGUE.md`) and the approval reference (`docs/erp/07_APPROVAL_WORKFLOW_REFERENCE.md`).

Tables added: thirteen (see `DB_CHANGES.md`) plus `core_sample_documents`. Permissions added for SYSADM, ITADM, ACCMGR, CFO, DIR and PM.
