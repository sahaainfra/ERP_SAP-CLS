# Discovery note 02.02

Inspected: after part 02.01 there was no organisation at all. `company_id` was a bare number on every table, with no company, branch, department, project or site record (searched: org_, branch, department, hierarchy, organisation, project). The only trace was the `site_id` and `project_id` columns that business tables already carry, the site holiday calendar of 01.03 and the thin user store of 02.01. So everything below is new; nothing existing was altered. Prerequisite 01.02 (database foundation, integrity registry, migrations) is in place and used; the numbering series (01.03) is not needed because organisation codes are typed by people; the calculation engine (01.06) has nothing to compute here; the event bus (01.04) is used for every change. The approval engine is the interim one of 01.03 (D-022).
