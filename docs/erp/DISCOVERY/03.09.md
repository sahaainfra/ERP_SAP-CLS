# Discovery note 03.09

Inspected (searched: english, formats, hindi, indian, localisation, number, ui_translations, i18n, labelHi, language): the application had a language choice (`ui_user_preferences.language`, `<html lang>`, the Devanagari typeface of 03.01), Hindi labels for the sign-in screen (`modules/iam/strings.js`), `label_hi` on navigation entries and field tiles, rupee and date helpers (`shared/money.js`, `shared/dates.js`), and no catalogue: every other screen carried its own English. There was no translation table, no amount in words, no hour-format choice, no lakh/crore abbreviations, no accessibility test and no rule against text in components. No i18n package is installed and none is added: the translator is 60 lines (ADR-146).

Prerequisite: 03.01 (tokens, themes, typography, preferences) accepted and pushed (`ff709a0`/`791169b`). The field screens are those of 03.06 (Field Home, Scan, device menu, install banners, location notice); the common components are the feedback states, the shell and the palette.
