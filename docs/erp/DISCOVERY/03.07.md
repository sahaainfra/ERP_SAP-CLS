# Discovery note 03.07

Inspected (searched: dashboard, framework, ui_dashboards, ui_widgets, widget, workspace, chart, kpi, svg, recharts): the application has no dashboard, widget or chart code. The nearest things are the launchpad of 03.05 (tiles, favourites, recent records, a count of what waits), the Data Health and Events and Jobs Monitor pages (their own tiles, fixed layouts, no personalisation), the List Report with its URL-less filters, and `design-tokens` with eight chart colours (`--erp-chart-1` to `-8`) that nothing uses yet. There is no chart package in the project and none is added: the chart library below draws SVG by itself.

Prerequisites: 03.05 (shell, registry, context) and 03.04 (Object Page, feedback states) accepted and pushed (`ea6219d`); 03.06 committed (`704b3e5`). Approvals (04.03), tasks (04.08), notifications (04.06), messages (05.01), attendance (07.05) and the document acknowledgement flow do not exist: the work sources that exist are the approval engine of 01.03 (requests waiting for a person), drafts, discussions with @mentions, holidays, the organisation and the sample material requests. Widgets for what does not exist are not drawn, and the task widget reads a registry of task sources that is empty until 04.08 (D-151).
