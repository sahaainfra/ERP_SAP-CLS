# Discovery 11.03: Submittals: material approvals, method statements and shop drawings

Inspected: the drawing register (11.01) and the RFI service (11.02) in the module `engg`, the workflow engine with resolvers and evidence providers (04.01), the file service and its entity registry (01.05), the parameter engine, notifications (04.06), the item master (06.x `mdm_items`), the project master and WBS (10.x), the list and export engines, the integrity registry, the navigation registry and the role templates (QCE, QCMGR, CM, DESIGN, SE, PM). No submittal table or page existed; procurement (15.x) and receiving inspection (18.x) do not exist yet.

| Requirement | Decision | Notes |
|---|---|---|
| FR-01 submittal types | New | MAR, method statement, shop drawing, sample, mock-up, product data, quality plan in `engg_submittals`. |
| FR-02 register with spec section, required-by linked to schedule and procurement lead time, status, revision | New | required-by is given, or worked out as the site need date minus the lead time minus the review days; the activity is a programme reference until 13.x; the item links to the item master. |
| FR-03 review cycle: prepare, internal review, submit to the consultant, response code A to D, resubmit | New + Reuse | internal approval `ENGG_SUBMITTAL` (quality control manager for materials, construction manager for method statements and shop drawings; never the sender); `engg_submittal_revisions` keeps each cycle and its code; response C starts a new revision; the response is recorded by the quality control manager or the design coordinator until the portal (25.04). |
| FR-04 approved makes feed procurement and receiving inspection | New | `engg_approved_makes` from an approved MAR; `/approved-makes`, `/submittals/po-check` and `procurementCheck` for 15.03, 15.05 and 18.03; event `engg.submittal.approved`. |
| FR-05 method statements linked to activities and HSE risk assessments | New | activity reference and `hse_ref` on the record and in the event for 19.01. |
| FR-06 schedule and overdue report | New | `/submittal-schedule` and the page. |
| BR-01 PO of an item with a pending required MAR warns or blocks (configurable) | New | parameter `engg.po_mar_control` (WARN default, BLOCK, OFF) per company; also warns or blocks for a make that is not approved. |
| Documents (`engg_submittal_docs`) | Reuse | the file service (entity `engg_submittal`) instead of a table of our own. |
| Permissions | New | `engg.submittal.{view,create,edit,delete,submit,approve,cancel,amend,print,export,respond}`. |
| Shared services | Reuse | workflow, files, parameters, notifications, lists and exports, audit, integrity registry, i18n, feature flags, navigation. |
