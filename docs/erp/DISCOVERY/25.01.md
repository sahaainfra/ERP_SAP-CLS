# 25.01 Portal framework discovery

The repository contains the global standards, UI v3 audit and design assets. The referenced UI v3 Design and Mobile Standard and P001–P166 verification report were unavailable in the checkout and attached materials.

Parts 02.07 and 06.04 have completion reports and are recorded as Ready for review. The security pipeline, route registry and MDM partner service are implemented. G1 and G2 require formal sign-off through Programme Gates. A read-only query of the development database found zero G1/G2 gate rows for its one company. D-693 tracks formal closure. D-080 tracks the existing staff-style invitation for external users.
