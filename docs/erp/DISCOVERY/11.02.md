# Discovery 11.02: RFI management

Inspected: the drawing register and its revisions (11.01), the module `engg` and its services, the workflow engine with resolvers and evidence providers (04.01), the file service and its entity registry (01.05), notifications (04.06), the project master, WBS, locations and BOQ (10.01 to 10.04), the list and export engines, the integrity registry, the navigation registry and the role templates (SE, CM, DESIGN, PM, PLAN, QS, DOC). No RFI table or page existed.

| Requirement | Decision | Notes |
|---|---|---|
| FR-01 RFI form on web and mobile with the location chain, drawing and revision, activity, BOQ item, specification clause, photos and markups, proposed solution, priority, required-by, cost and time impact flags | New | `engg_rfis`; links validated against the project; the Raise RFI page is built for the phone (large targets, camera or gallery, finger markup on a canvas saved as a picture, queue message when offline). Photos and markups go through the file service (entity `engg_rfi`), so `engg_rfi_attachments` is not created. |
| FR-02 routing by discipline and impact; ball-in-court tracking | New + Reuse | issue approval `ENGG_RFI_ISSUE` (design coordinator); the consultant answers (recorded by the design coordinator until the portal 25.04); verification and closure `ENGG_RFI_CLOSE`; `ball_in_court` and `engg_rfi_routing` give the timeline. |
| FR-03 response capture; a design change links a drawing revision or an instruction; variation | New | response type, text, revision, instruction reference, variation reference (text until 21.05). |
| FR-04 ageing and SLA by priority with escalation; critical-path RFIs highlighted | New | age from the issue date; SLA 2, 5, 7 and 14 days for critical, high, medium and low; `escalate` notifies the design coordinators and the raiser once; a flag marks an RFI on the critical path (the schedule, 13.x, does not exist yet). |
| FR-05 register with filters; impact log for claims and EOT | New | list engine, export; cost and time impact columns and totals on the dashboard. |
| FR-06 hold flag shown as a constraint for the look-ahead | New | `hold_activity`; `/engg/rfis/constraints` and `rfiConstraintsOf` give the open holds for 13.04. |
| BR-01 no close before the raiser's lead verifies; design change needs a revision or instruction | New | the closure chain ends with the raiser's lead (the project manager of the project, never the raiser); the rule is checked at answer and at closure. |
| BR-02 a time impact creates a delay-register draft | New | `engg_rfi_delay_drafts` until 13.05 takes it over; the event carries the draft id. |
| Event `engg.rfi.responded` | New | also `engg.rfi.issued`, `engg.rfi.closed`, `engg.rfi.escalated`. |
| RFIs on the drawing page | Repair | the tab of 11.01 now lists the RFIs of the drawing. |
| Permissions | New | `engg.rfi.{view,create,edit,delete,submit,approve,cancel,amend,print,export,respond}`. |
| Shared services | Reuse | workflow, files, notifications, lists and exports, audit, integrity registry, i18n, feature flags, navigation. |
