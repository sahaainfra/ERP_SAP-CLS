# Part 12.01 discovery: Project budget preparation and approval

Date: 2026-11-13. Module `bud`, flag `ff.bud.p1201`. Depends on 10.04 (BOQ) and 06.05 (cost codes); used by 12.02 to 12.04.

## Sources read
- Baseline packs (`proj_baseline_packs.snapshot_json`): BOQ items with norm lines and rates, `boqCost`, indirects, contingency and risk allowances (10.02).
- BOQ (`proj_boq_versions`, `proj_boq_lines`, `proj_boq_line_wbs`, `proj_boq_line_norms`): the quantities, the WBS split and the norms; the norms carry no rate and no resource id (D-457).
- WBS, work packages and control accounts (`proj_wbs.is_control_account`, `proj_work_packages.wbs_ids_json`), cost heads and cost codes (`fin_cost_heads`, `fin_cost_codes`), project contract value and dates (`proj_projects`).
- Workflow engine (band step on `amount`, as the baseline pack), parameters, notifications, integrity registry, route policy, authz templates.

## Decisions
ADR-442 to ADR-447. Nothing existing is altered: three new tables and a seed. There is no schedule yet, so phasing from the schedule is refused (D-456).

## Rights
Preparers: quantity surveyor and project controls manager (create, edit, submit, cancel, amend). Reviewers: project manager, project director, director (view, approve, print, export). Commercial manager, planner and construction manager read.
