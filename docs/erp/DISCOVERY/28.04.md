## Decisions

| Requirement | Existing | Decision |
|---|---|---|
| FR-01 OCR pipeline on upload with searchable text | File service events, jobs | **Extend**: a consumer of `core.file.available` queues `ai.docintel.extract` for PDF, text and image files of companies with the flag on. It reads the text layer of a PDF (pdfjs) and plain text. Scanned images go to a local OCR engine when one is installed; otherwise they are queued with the status "No text found" (D-786). **New** `di_extractions` keeps the text, which the worklist searches. |
| FR-02 Extractors and their targets | 22.06, 11.05, 21.01, 04.10 | **New** rule-based extractors with a confidence and source position per field: the invoice header (GSTIN with its check digit, number, date, taxable value, GST, total, cross-checked; vendor), the certificate (number, issuer, issue date, expiry), the letter (reference, date, subject, sender, category) and contract clauses (number, title, category, time-bar). **Reuse** the owners' services to create drafts. |
| FR-03 Classification, near-duplicates | — | **New** weighted cues for each type. Identical bytes (sha256) are a duplicate; a 64-bit SimHash of word 3-shingles within 8 bits (a company parameter) is a near-duplicate. |
| FR-04 Review UI with confidence and source highlight | — | **New** worklist `/ai/documents` (oldest first, SLA chip) and a review with the document text (source marks) beside the fields; accept, edit or reject. |
| BR-01 Low-confidence fields confirmed explicitly | — | A field below `ai.docintel.confirm_below` (0.85) used as suggested must be confirmed, or acceptance is refused (422); editing it counts as checking it. |
| T-01 Accuracy measured; nothing applied without acceptance | — | A labelled sample set in the tests (field accuracy), and an accuracy report from reviews (fields accepted unchanged). No draft exists before acceptance. |
| Roles | Templates | `ai.docintel.view`, `review` and `run` for FINEX, DOC and COMMGR; AUD reads. A person sees an extraction only within their scope and only if they may open the file. Each draft is created with the reviewer's own rights in the owner module. |
| Owned defects D-236, D-244 | — | Not about reading documents (PDF/A output, cryptographic signatures): re-assigned to 29.07 and 30.05. |
