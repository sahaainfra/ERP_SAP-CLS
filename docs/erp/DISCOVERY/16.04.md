# Part 16.04 discovery: Material Issue, Site Returns & Consumption

Date: 2026-11-12. Depends on 16.03 (stock, GRN) and 14.01 (work authorisations, `site_work_authorisations` and `site_wa_resources`). Reads 15.01 (material requests) and the BOQ norms (`proj_boq_line_norms`).

## Findings
| Requirement | Decision | Evidence in the repository |
|---|---|---|
| FR-01 issue slip from MR or WA, receiver signature or OTP | New | No issue document exists. The work authorisation carries material resources (item, planned quantity); the material request carries approved lines (`issue_qty` on `proc_mr_lines` is told by the event). The stock engine (16.01) posts the issue. New `inv_issues` and `inv_issue_lines`; acknowledgement by code or signature. |

| FR-04 returns from site | New | `inv_site_returns`; the stock engine's RETURN entry at the issue rate. |
| FR-05 consumption confirmation from the DPR | Not built (D-556) | The DPR (14.02) does not publish material quantities. |
| FR-06 free-issue ledger | New | `inv_free_issue_ledger`; BOQ norms exist (`proj_boq_line_norms`); the certified quantity does not (D-557): `inv_sub_certified` adapter. |
