# Discovery note 04.06

Inspected (searched: centre, engine, notification, ntf_deliveries, ntf_notifications, ntf_preferences, ntf_templates, real, time, socket): no `ntf_*` table existed. What did: the event bus and outbox with consumers (01.04); the workflow engine's `workflow.notification.requested` events, which named the template and the people but had no one to deliver them ("the notification service (04.06)"); the room guard of part 02.07 (`securityOf(db).rooms`), written for the real-time server "until it exists"; the bell of the shell, which counted requests waiting; the sign-in notifier that sends e-mail, text and WhatsApp through the integration hub; the Web Push sender and the device subscriptions of 03.06; the screen language of 03.09; the audit trail, parameters, flags, list, and export frameworks. **There was no Socket.IO server**: the prompt says "reuse", but only the guard existed, so the server is new (ADR-183). Prerequisites 01.04 and 02.04 are accepted; the communication gateway (04.07) is not, so the channels go through stand-in gateways behind one interface.
