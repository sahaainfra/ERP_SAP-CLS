# Discovery 10.08: Project 360 and the project dashboard

Inspected: the project master and its health (10.01: lifecycle, dates, milestones, `healthProviders`), the BOQ, WBS, baseline, team, meetings, risks and map services of 10.02 to 10.07, the dashboard and widget framework (03.07: `ui_widgets`, `widgetRegistry`), the project activity feed (04.14: `collabOf(db).timeline.project`), the parameter registry and the export service. A project health summary already existed on the portfolio list of 10.01 (time only); there was no Project 360 page, no slot catalogue and no portfolio grid.

| Requirement | Decision | Notes |
|---|---|---|
| FR-01 header: project, client, contract value (original and revised), dates, lifecycle, PM, health (time, cost, quality, safety, cash) | New + Reuse | read from the project master's own fields (the permission of the master is not required of a team member); original value from the signed-off baseline pack; health computed here, six dimensions. |
| FR-02 widget slots registered by modules | New + Reuse | `proj_360_widgets` and `registerProject360Widget`; ten live providers call the services of 10.01 to 10.07 and 04.14; ten slots wait for their part. |
| FR-03 tabs | New | overview, time, cost, resources, quality and HSE, commercial, documents, activity. |
| FR-04 drill-down, period selector, PDF snapshot | New | every figure carries its link; month selector; export through the export service, audited. |
| FR-05 portfolio view | New | `/proj/portfolio-overview` and the page, scoped by the person's grants. |
| FR-06 empty states name the module, never fake numbers | New | `NOT_LIVE` slots; "no data" health. |
| BR-01 RAG thresholds per company | New + Reuse | parameter `proj.rag_thresholds`, changed through the parameter engine (company scope, effective date, reason). |
| BR-02 widgets only for modules the person may use | New | each slot carries its permission; a live widget without it is absent. |
| Dashboard framework | Reuse | three `ui_widgets` rows with providers. |
| Workflows | None | this part has no business approvals; its one configuration, the thresholds, is a parameter. |
| Shared services | Reuse | permissions, parameters, widgets, export, audit, i18n, feature flags. |
