# Discovery note 04.11

Inspected (searched: delivery, document, generation, print, templates, tpl_deliveries, tpl_generated_docs, tpl_templates, pdf, qr): no `tpl_*` table existed. What did: the document management service with the file entity registry (04.10), the file service with scan and signed links (01.05), the communication gateway with attachments as links, e-mail and WhatsApp routing and receipts (04.07), the workflow engine with document types, evidence providers and hooks (04.01), the QR resolver registry (03.06), the job runner with progress (01.04), the notification templates (04.06), the export writers, the IBM Plex fonts in `@fontsource` (03.01), `pdf-lib`, `qrcode` and `sharp`. Prerequisite 04.10 is accepted (completion report in `docs/erp/COMPLETION/04.10.md`); 01.03 is accepted. Part 04.12 (verification page and digital signature) is not built: a thin adapter is documented in D-239.
