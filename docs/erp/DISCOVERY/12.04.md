# Part 12.04 discovery: Head-office and department overhead budgets

Date: 2026-11-16. Module `bud`, flag `ff.bud.p1204`. Depends on 06.05 (accounts, cost centres' accounts) and 12.01 (the budget service, the approval and version pattern); provides the overhead pool to 23.10.

Searched for `bud_alloc_rules`, `bud_dept_budgets`, `bud_dept_lines`, `budgets`, `department`, `head`, `office`, `overhead`: nothing existed except the head-office and site overhead *lines* of a project budget (12.01, `bud_lines.line_kind = OVERHEAD`, default cost code `HOH-ADMIN`), the organisation tables (`org_departments`, `org_cost_centres`, `org_assignments` with the HEAD role), financial years and periods (`core_financial_years`, `core_periods`), the chart of accounts (`fin_accounts`) and the workflow, notification, audit, object-page and file services.
