# Discovery note 07.03

Inspected (searched: assignment, deployment, hr_crew_members, hr_crews, hr_deployments, hr_transfers, project, site, transfers): there was no deployment, crew or transfer anywhere. What exists and is reused:
- the **employee master of 07.01** (`hr_employees`, the user link, the `employeeRelated` tab hook of Employee 360, the lookup `hr/employees`, the import conventions of `integrations.js`);
- the **permission engine** (02.04): role holdings, scopes (company, project, site), `check`, `scopeFilter`, the 30 s cache and `invalidate()`; the organisation tables (`org_projects`, `org_sites`, `org_assignments` with the project manager of each project);
- the workflow engine and approval matrix (04.01, 04.02): roles, resolvers, conditions on the context, distinct approvers, resubmit, withdraw, abandon; evidence panels; the object-type registry for the Related/Trace and timeline tabs;
- notifications (04.06), parameters, the numbering adapter used by 07.01/07.02, the List Report and export service, the Excel import engine (04.13), the job scheduler, the widget registry, the messaging auto groups (05.04);
- not present: the labour register (07.08), attendance and visits (07.05), resource planning (17.08), a WBS master, Project 360 (10.08), a PDF/image engine for the board.
