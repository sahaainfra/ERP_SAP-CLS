# Discovery note 01.01

Inspected: after part 00.03 the server was a flat set of files (`app.js`, `auth.js`, `config.js`, `db.js`, `errors.js`, `flags.js`, `about.js`) with the routes, validation and a few business rules written together in `app.js`, a correlation-ID middleware and an error handler in `errors.js`, and a single API helper on the client. There was no shared validation helper beyond one function in `app.js`, no list helper, no money or date library, no health endpoint beyond `/api/health`, no request log, and no module structure. The only "legacy" code is this repository's own parts 00.02 and 00.03, so no outside adapter was needed; the contract snapshot protects their routes. Prerequisite 00.02 is "Ready for review" (not yet Accepted) and was reused as is.

| Requirement | Existing | Decision | Where |
|---|---|---|---|
| FR-01 module boundaries, folder structure, legacy wrapped | Flat files | Repair | `src/server/platform/*`, `src/server/modules/core/*`, `src/client/platform`, `src/client/modules/core`, `docs/erp/ARCHITECTURE.md` |
| FR-02 shared pipeline: correlation ID, request log, body limit, JSON, error handler | Correlation ID, limit and handler existed; no request log; bad JSON gave 500 | Extend | `platform/http/{pipeline,logger,errors}.js` |
| FR-03 validation helper with field-level details | One inline function | Extend | `platform/validation/index.js` |
| FR-04 pagination, sorting, filtering helper | Inline `page` and `pageSize` only | New | `platform/pagination/index.js`; flag list adopted it |
| FR-05 base service and repository helpers | Transaction helper only | Extend | `platform/db/repository.js` (optimistic update, version check, soft delete, standard columns), `platform/audit`, `platform/events` |

| FR-07 frontend API client, TanStack Query conventions, route registration | One `api()` function and a hard-coded route table | Repair | `src/client/platform/{api,query,shell}`, pages moved onto query hooks |
| FR-08 `/health/live` and `/health/ready` (DB, queue, storage) | `/api/health` only | New | `platform/health`, `app.js` |
| FR-09 decision records | Free-form notes | Extend | ADR-01 to ADR-13 in `DECISIONS.md` |
