# Discovery note 05.01

Inspected (searched: direct, group, messages, msg_conversations, msg_members, msg_messages, project, site, unified, chat, workchat, conversation, thread): there was **no Team Chat or secure messaging store** in this repository (the context note says Prompts 27 to 29 are reported built; only the gateway of 04.07 exists). What did exist: the communication gateway log `comm_messages` with a `conversation_key` for threads (WhatsApp, e-mail, SMS, push; 04.07); record discussions `col_comments` (04.14), earlier record comments `ui_record_comments` (03.04) and task comments `tsk_comments` (04.08); the real-time layer with rooms and a reserved `conv:<id>` kind that no one could join (04.06); notifications with the category `mentions` (04.06); the file service and its entity registry (01.05); the object type registry (03.04) for record access and summaries; assignments `iam_assignments` with scope types (02.04); the navigation group `g-messages`; the pop-out-free shell and `useLiveRefresh`.
