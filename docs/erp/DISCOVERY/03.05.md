# Discovery note 03.05

Inspected (searched: application, context, navigation, registry, shell, switcher, ui_favourites, ui_navigation_entries, ui_recent_records, breadcrumb, sidebar): the shell today is a top bar of every permitted page as a flat link row (`src/client/App.jsx`), built from a code-only route registry (`platform/shell/registry.js`, `registerModule`). There is a project and site switcher (`modules/iam/components/ContextSwitcher.jsx`) that keeps the choice in this browser only, and `GET /api/v1/iam/org/context` that lists the projects and sites in the person's scope. No navigation tables, favourites, recent records, breadcrumbs, quick create, launchpad or shortcuts exist. Pages already set their own `document.title`.

Prerequisites: 03.01 (tokens, themes, `Icon`) accepted; 02.04 (permissions, scopes) accepted. The notifications bell (04.06), messages (05.01), global search (03.08), help (29.08) and dashboard tiles (03.07) are later parts and are not simulated.
