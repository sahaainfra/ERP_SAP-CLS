## Requirement by requirement

| Requirement | Decision | What |
|---|---|---|
| FR-01 GSTR-2B import and matching | **New** | `gst_2b_imports`, `gst_2b_lines`; GSTN JSON (b2b, cdnr) or CSV; GSP refused with guidance (D-735); matching by GSTIN, normalised number, date and amount; fuzzy number (same amount and date ±3 days, a number that ends with the other or differs by two characters); rate change by time of supply not a false mismatch; missing in 2B from the books |
| FR-02 mismatch resolution | **New** | owner, follow-up (`gst_recon_followups`, event `fin.gst_recon.followup` for the vendor portal of 25.02), accept / resolve / reopen; daily job tells the owner of a follow-up due |
| FR-03 ITC review | **New** (approval-controlled) | `gst_itc_reviews` + lines: eligible, blocked s.17(5) (expense heads by parameter), held (not in 2B / mismatch), reversed (unpaid beyond 180 days, by the unpaid share), override with a reason; ACCMGR → CFO (`FIN_ITC_REVIEW`); reversal journal Dr 560011 Cr GST input by head; amendment |
| FR-04 GSTR-1 / GSTR-3B | **New** | B2B, B2CS, CDNR and HSN summary from the sales; 3B: 3.1(a), 3.1(d), 4(A), 4(B), 4(D), payable; prepared, exported (JSON), marked filed with the ARN (`gst_return_filings`) |
| FR-05 TDS | **New** + **Reuse** 166.8 forms | `tds_returns` by quarter and form (26Q / 140 from the master), challans, prepared only when deposited covers deducted, filed with the token; certificate (16A / 131) per deductee; 26AS / AIS import matched to `ar_receipts` (`tds_26as_lines`); 27EQ has no source (D-736) |
| FR-06 compliance calendar | **Reuse** 166.8 + **Extend** master rows | GSTR-1, GSTR-3B and the 2B reconciliation added as system rows; each obligation's status from the filings, the ITC review and the TDS returns |
| BR-01 | **New** | ITC claimed only for matched/eligible invoices; held ones only by override with a reason (≥ 10 characters); a blocked one never |
| §7 pages | **New** | GSTR-2B Reconciliation & ITC Review (worklist cards with SLA chips, pill tabs, ITC review object with the CFO's decision on the phone); GST & TDS Returns, Compliance Calendar (chart first, cards, sticky totals) |
