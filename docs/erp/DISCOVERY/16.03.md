# Part 16.03 discovery: Goods Receipt (GRN), Inspection Hold & Returns to Vendor

Date: 2026-11-12. Depends on 16.02 (gate entries, unloading store, weighment, vendor-return gate pass) and 16.01 (stock engine). Reads 15.05 (orders) and 15.06 (mandatory inspections).

## Findings
| Requirement | Decision | Evidence in the repository |
|---|---|---|
| FR-01 GRN from gate entry or PO | New | No GRN table exists. `proc_po_receipts` (15.05) holds a received quantity per order line loaded from outside (`receipts/ingest`); it is kept and fed by the event. New `inv_grns` and `inv_grn_lines`; prefill from `inv_gate_inward` (16.02) and `proc_po_lines`. |
| FR-02 inspection hold, partial acceptance | New on 16.01 | `inv_balances.qty_inspection` exists (16.01) and is used by the hold; new per-line inspection status and QC action. Mandatory inspection of an order (`xpd_inspections.mandatory`, 15.06) defaults the line to inspection. |
| FR-03 tolerance for excess and short | New | Parameter `inv.grn.excess_tolerance_pct`; short receipt is simply less than the balance (the order stays open). |
| FR-04 direct receipts to WBS and cost code | New | A non-stock item moves no stock; its WBS or cost code is required (inherited from the order line). |
| FR-05 return to vendor | New | `inv_rtvs`; gate pass type VENDOR_RETURN of 16.02; debit note flag for 23.03. |
| FR-06 posting, PO received quantity, accrual, vendor performance | New and event | `inv.grn.posted`; subscriber in procurement calls the existing receipt loading. Accrual, scorecard, matching: consumers do not exist yet (D-553). |
| FR-07 photos | Reuse | Document service (`core_files`, entity `inv_grn`). |
| BR-01 accepted <= received <= balance + tolerance; GRN without PO only by emergency | New | `buildLines`, `header`. |
| BR-02 stock at acceptance; inspection items stay in inspection stock | New | `decide`, ADR-569, ADR-570. |
| BR-03 rate from the PO | New | The ledger rate is the order rate; no landed cost (D-554). |
| Workflow GRN SK to STOREMGR or CM (excess to PROCMGR); RTV SK to PROCMGR | Reuse the engine | `workflowTypes.register` `INV_GRN`, `INV_RTV`. |
| Pages (mobile create, GRNs list and object, returns) | New | Three pages under the Stores group. |
