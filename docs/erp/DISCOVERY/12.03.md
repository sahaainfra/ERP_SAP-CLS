# Part 12.03 discovery: Budget check service and commitment ledger

Date: 2026-11-15. Module `bud`, flag `ff.bud.p1203`. Depends on 12.01 (and 12.02 for the budget in force); used by 14.01, 14.07, 15.01.

| Requirement | Decision | Notes |
|---|---|---|
| FR-01 check API: available = budget − committed − actual; OK, warning, block per mode per cost head | New (`POST /check`, `GET /availability`, `bud_check_config`) | The budget is the approved version in force (`currentOf`). |
| FR-02 commitment ledger from PR, PO, WO, hire, service orders; amendments; short-close, cancel | New (`bud_commitments`, `bud_commitment_log`) | Fed by events and a system endpoint; publishers do not exist yet (D-463). |
| FR-03 actuals reduce commitments | New (`bud_actuals`) | Idempotent by source; no double count (ADR-454, ADR-456). |
| FR-04 over-budget exception through the control engine | Reuse 04.04 (`CP-BUD-01`) | No ledger-side override. |
| FR-05 availability widget for forms and evidence panel | New component `AvailabilityPanel` | Shown on the ledger page; forms of M15 and M21 do not exist yet. |
| FR-06 commitment report | New (`GET /ledger`, documents, CSV) | By WBS, cost code, cost head, vendor. |
| BR-01, BR-02 | New | ADR-454, ADR-458. |
| Config maker-checker (section 9) | Reuse 04.01 | `BUD_CHECK_CONFIG`: the project director checks. |
| Permissions | New `bud.ledger.*`, `bud.check.*` | `bud.ledger.post` only for the system administrator (the system service). |

Prerequisites: 12.01 and 12.02 are Ready for review, used through the budget service (`budgetBase`, `currentOf`). The control engine, workflow, notifications, audit and the event bus are used as they are.
