# Discovery note 03.04

Inspected (searched: approval, attachments, object, page, panel, timeline, comment, discussion, toast, banner, confirm, reason code, offline, trace, amendment, version, print): there is no Object Page. Every record page builds its own header, tabs and actions. What exists and is reused: the approval engine of part 01.03 (`platform/approvals`, a stand-in for the workflow engine 04.01: ordered role chains, approve / reject / return with a mandatory comment, no self-approval, one person per step, a handler applied in the same transaction as the last approval; no delegation, SLA or escalation), the attachment panel of 01.05 (`FileUploader`, `AttachmentList`, record types registered in `fileEntities`), the record history of 02.06 (`RecordHistory`, `core_audit_log` through the audit chain), the calculation trace view of 01.06 (`TraceView`), `StatusBadge` and tone classes (03.01), `FormDialog`, `QueryState`, `Loading` and `FieldError` (01.03 era), the form framework (03.02) and the List Report (03.03) with the reference register Sample Material Requests. Not existing: toasts, banners, a confirmation dialog with reason codes, a progress dialog, an offline banner, illustrated empty states, comments or mentions (04.14), version snapshots, record print (04.11), related-record links, required-document checklists. The sample request had no approval of its own: submit numbered it and stopped. Parts 03.02 and 03.03 are accepted and pushed (791169b).
