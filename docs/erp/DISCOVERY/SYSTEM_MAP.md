## Build and run (package.json scripts)

- `npm run build`: `vite build`
- `npm run deploy`: `node scripts/deploy.mjs`
- `npm run dev`: `concurrently -k -n api,web "node --env-file-if-exists=.env --watch src/server/index.js" "vite"`
- `npm run erp:audit`: `npm audit --audit-level=high`
- `npm run erp:coverage-gate`: `node scripts/coverage_gate.mjs`
- `npm run erp:discover`: `python scripts/erp_discover.py`
- `npm run erp:golden`: `node scripts/golden.mjs`
- `npm run erp:migration-check`: `node scripts/migration_check.mjs`
- `npm run erp:regression`: `node scripts/regression.mjs`
- `npm run erp:schema-diff`: `node scripts/schema_diff.mjs`
- `npm run erp:secret-scan`: `node scripts/secret_scan.mjs`
- `npm run lint`: `eslint .`
- `npm run migrate`: `node --env-file-if-exists=.env scripts/migrate.mjs up`
- `npm run migrate:down`: `node --env-file-if-exists=.env scripts/migrate.mjs down`
- `npm run package`: `node scripts/package.mjs`
- `npm run rehearse`: `node scripts/rehearse.mjs`
- `npm run release`: `node scripts/release.mjs`
- `npm run rollback`: `node scripts/rollback.mjs`
- `npm run seed:demo`: `node --env-file-if-exists=.env scripts/seed_demo.mjs`
- `npm run start`: `node --env-file-if-exists=.env src/server/index.js`
- `npm run test`: `node --test --test-reporter=spec "tests/*.test.js"`
- `npm run test:coverage`: `node scripts/test_coverage.mjs`
- `npm run test:e2e`: `playwright test`
- `npm run typecheck`: `tsc -p tsconfig.json --noEmit`

## Start locally

1. `npm install`
2. copy `.env.example` to `.env`
3. `npm run build` (serves the client from `dist/` on the API port) or `npm run dev` (API 3000 + Vite 5173)
4. `npm run start`; the database is created and migrated on start-up
