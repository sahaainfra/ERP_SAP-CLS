## 4. Data
- Migration `20261209000328_field_p16603` (up and down): the flag; new tables `ui_navigation_labels` (the Telugu label of a registry entry, given
  by the API as `labelTe`), `ui_field_tile_rules` (a tile's roles, colour, Telugu label and flags) and `ui_bottom_bar`; 21 field tiles;
  `ui_user_preferences` and `ui_translations` rebuilt with `te` in their language check (no table references either). The prompt asks for a
  `label_te` column: every migration of this repository must run twice without failing (`scripts/lib/migration_check.mjs`) and SQLite cannot add a
  column only when it is missing (no earlier migration adds one), and `ui_navigation_entries` cannot be rebuilt inside the migration's transaction
  while other tables reference it, so the label sits in its own table, one row per entry and language.
- `iam_users.language` and `ntf_templates.lang` keep `en`/`hi` (28 tables reference `iam_users`; a rebuild is not safe here): a person's screen
  language is the preference of `ui_user_preferences`, which allows `te` (D-675).
