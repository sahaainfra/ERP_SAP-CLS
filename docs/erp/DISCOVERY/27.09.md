## Decisions

| Requirement | Existing | Decision |
|---|---|---|
| FR-01 Detection rules library | Signals above | **New** library of 13 rules in `bi/leakage.js`, each reading its owner's records read-only and returning hits with evidence and value at risk: duplicate invoices, duplicate payments, split POs, PO above benchmark, consumption above norm, fuel anomaly, attendance anomaly (proxy punches), idle hired equipment, stock ageing, unbilled work ageing, overdue approvals, unregularised emergency purchases, repeated exceptions by user. Run as a background job daily at 05:30 IST and on demand. |
| FR-02 Findings with evidence, value, owner, status, outcome | — | **New** `det_findings` (deduplicated by evidence key). Owner: the record's own person where the rule has one (approver, raiser), else the RACI accountable person (04.05), else the project manager, else a holder of the rule's owner role. Each finding gets a task (04.08), a notification and an event; overdue findings escalate to PD and AUD once. |
| BR-01 Advisory, closure needs an outcome | — | Nothing is blocked. Closing requires CONFIRMED_LOSS (with the amount), PREVENTED or FALSE_POSITIVE; a database check enforces it. |
| §9 False positive: owner → AUD | Workflow engine | **Reuse** `workflowTypes.register` (`BI_FINDING_FP`, one AUD step); return or reject sends the finding back to review; the requester never approves. |
| "Outcomes improve rules" | — | A closed finding is never raised again for the same evidence; the false-positive rate per rule is shown with the rule; thresholds change only by maker-checker (`det_rules` versions, AUD or CFO approves). |
| FR-03 Control tower | 04.04 tables | **New** tower: value at risk, overdue, confirmed loss, prevented, false-positive rate, awaiting the auditor; by type, by project, largest findings, controls by mode, findings and exceptions trend, my pending actions. |
| Roles | Role templates | **New** `bi.leakage.view`, `bi.finding.{view,act,approve,export}`, `bi.det_rule.{view,configure,run}` for AUD, CFO, PD, PCMGR; owners act on their own findings without them. |
| Ghost workers | — | **Not built** (no payroll-to-attendance match): D-780. |
