## Decisions

| Requirement | Existing | Decision |
|---|---|---|
| FR-01 Ticket from any page with page, record, correlation ID, screenshot; categories, priority, team, SLA, status, resolution; e-mail/WhatsApp updates | Correlation IDs, notifications, files | **New** Help button in the shell and `hd_tickets` with the captured context, routing by category to a team, SLA by priority (parameters `hd.sla.*`), timeline `hd_ticket_notes`, updates through the notification service, escalation job (team lead, then ITADM). |
| FR-02 Data corrections routed to module owners with approval, never direct DB edits | Approval engine | **New** `hd_corrections`: approved by the module owner, then AUD for financial modules; the owner makes the change through the module's own transaction and records its reference, which resolves the ticket (BR-01). |
| FR-03 Contextual help per page; guided tours per role | — | **New** `hd_articles` with routes and roles; the Help panel lists a page's articles and its tour; `hd_tour_views` records who has seen it. |
| FR-04 Knowledge base; release notes from 00.03; in-app announcements | Release tool, Markdown | **New** knowledge base (versioned articles), the release notes as written by the release tool, announcements between dates. |
| FR-05 Satisfaction rating; support dashboard | — | **New** rating 1–5 by the person; dashboard with open, breached, resolution time, satisfaction and breakdowns. |
