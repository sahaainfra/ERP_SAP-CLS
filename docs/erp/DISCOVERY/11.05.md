# Discovery 11.05: Correspondence register: inward and outward letters and notices

Inspected: the document management service (04.10: documents, versions, register), the file service and entity registry, the workflow engine with resolvers and evidence providers (04.01), the alert engine and its datasets (04.09), notifications (04.06), the parameter engine, the project master (10.01), the RFI, submittal, drawing and transmittal records of the module `engg` (11.01 to 11.04), the list and export engines and the role templates (DOC, PM, COMMGR, PD, CM, SE). No correspondence table or page existed; the template engine (04.11), the mail channel (04.07), the claims (21.06), variations (21.05) and site instructions (14.04) are not available.

| Requirement | Decision | Notes |
|---|---|---|
| FR-01 inward correspondence: received date, party, reference, subject, category, clause, response due, assignee, scan, linked records | New | `engg_letters` (direction IN) with numbering `PROJECT/IN/0001`; the scan is a file of the file service (entity `engg_letter`); `document_id` can point at a document of 04.10; links in `engg_letter_links`. |
| FR-02 outward correspondence from templates, approval before issue, issue mode with acknowledgement proof | New + Reuse | six standard texts held in the service (the print templates, 04.11, will replace them); workflow `ENGG_LETTER`; issue by e-mail, courier, portal or hand with a delivery reference; the acknowledgement (who, when, note, scan) is the proof. Sending the e-mail itself (04.07) is not done: the mode and the reference are recorded. |
| FR-03 thread view and response tracking with overdue alerts | New | `parent_letter_id`; `/letters/:id/thread`; an inward letter is answered when an outward reply was issued; overdue replies alert the assignee once. |
| FR-04 notice tracking for time-bar clauses with countdown alerts linked to claims | New | `engg_time_bars` (clause, event date, days allowed, deadline, claim reference, owner) served by an outward letter that names the bar; alerts at 7, 3 and 1 days (parameter `engg.time_bar_alert_days`) and at lapse; alert dataset `engg.time_bar` for the alert engine. |
| FR-05 search and tagging; OCR | New + deferred | search over number, reference, subject, party, clause, tags and the text of the letter; OCR of scans waits for 28.04. |
| BR-01 outward letters on letterhead only after approval; numbering per project series | New | the number is taken when the letter is approved; print shows the letterhead and the number only for an approved, issued or acknowledged outward letter, a plain draft otherwise. |
| BR-02 notices with contractual time limits create countdown alerts | New | see FR-04. A contractual notice is approved by the commercial manager, an ordinary letter by the project manager. |
| Confidentiality ("project leads: view per confidentiality") | New | letters marked confidential are seen, registered and exported only by those who hold `engg.letter.view_confidential`; the list, search, thread and files all respect it. |
| Output: evidence links to claims, variations and site instructions | New | events `engg.letter.registered`, `engg.letter.issued`, `engg.timebar.*` carry the links. |
| Permissions | New | `engg.letter.{view,create,edit,delete,submit,approve,cancel,amend,print,export}` plus `issue` and `view_confidential`. |
| Shared services | Reuse | workflow, files, alert engine, notifications, parameters, lists and exports, audit, integrity registry, i18n, feature flags, navigation. |
