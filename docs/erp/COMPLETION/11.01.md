## 2. What was built
- **Database** (migrations 163, 164; nothing existing altered): `engg_drawings`, `engg_drawing_revisions`, `engg_drawing_links`, `engg_transmittals`, `engg_transmittal_items`, `engg_copies`; seed: the flag, the navigation group Engineering and Drawings with four entries, six page-tracker rows, the notification template `engg.drawing.superseded` (in-app and e-mail, English and Hindi).
- **Server** (`modules/engg`): `drawings.js` (register, revisions, supersession, controlled copies, site view, schedule, dashboard, use check, import, print, export; workflow `ENGG_DRAWING_IFC`, resolvers `engg.docCheck` and `engg.pm`, evidence, file entity `engg_drawing_revision`), `transmittals.js` (transmittals, responses; workflow `ENGG_TRANSMITTAL`), `routes.js`, `validators.js`, `index.js` (events, integrity registrations).
- **API**: 39 routes under `/api/v1/engg`, all in the route policy and `openapi.yaml`.
- **Permissions**: 11 for drawings and 11 for transmittals; granted to document controller, design coordinator, project manager, project director, construction manager, site engineer, planner, quantity surveyor, project controls manager and director.
- **Browser**: Drawings Dashboard, Drawing Register with the new-drawing form, Drawing (revisions, compare viewer, transmittals, links, controlled copies, RFIs), Transmittals with the new-transmittal form, Transmittal (responses), and Current Drawings for my Site (mobile); English and Hindi (namespace `engg`).
