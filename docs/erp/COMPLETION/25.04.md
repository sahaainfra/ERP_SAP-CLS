## 2. What was built

The internal `clientConsultantScope` adapter reuses the 25.01 session, live contact or stakeholder, and company gate checks. It requires an `X-CLI` or `X-CON` session, the company’s `ff.portal.p2504` flag, and an active company project with a matching active site when a site is assigned. It returns a frozen grant containing account, role, project, site and source identity IDs. Company-wide contact assignments cannot enter this project workspace. This grant is an input to the owning service’s explicit record sharing or routing check.

The brief limits this build to the adapter and its default-off flag. The business APIs, pages, decisions, reports, exports, notifications and event integrations await prerequisite acceptance.
