## 7. How to verify manually
1. As the project manager open **Stakeholders**: add the client with an e-mail, then the **Communication matrix**: weekly progress report to the client. A site engineer sees the same register with the contacts hidden.
2. **Project Team**: add a person with a project role; another project manager and the project director approve it in the inbox; the member shows "waiting for the role engine", whose request is in the role engine's inbox.
3. As the minute-taker open **Meetings**, create a meeting (chair, minute-taker), add attendees (colleagues and an external one), the agenda, the minutes, a decision and an action with an owner and a date; **Send the minutes to the chair**. The chair approves in the inbox: the minutes are issued and locked, the owner has a task, the attendees are told.
4. The owner opens the meeting and **Starts** and **Marks done** the action; **Action Item Tracker** shows it. **Revise the minutes** starts a revision with the same number.
