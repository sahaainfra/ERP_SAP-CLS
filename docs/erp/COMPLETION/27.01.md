## 2. Delivered

**Report Catalogue** at `/bi/reports` lists Project Status and links to existing module reports for progress, budget vs actual, procurement, open purchase orders, stock, concrete consumption, plant utilisation, attendance, payroll, quality, HSE, billing, collections, payables ageing and cash position. Searches match titles. Each listed report requires its owning module flag and permission. Linked reports open in the module that applies their parameters, scope and masks.

Project Status uses the Project Setup register for lifecycle and approval status and project health. The report supports lifecycle filtering, pagination and CSV, XLSX and PDF exports. Exports apply both view and export grants, omit commercial fields and record an audit. When the result exceeds the company's direct-export limit, My Exports shows the queued job. The job checks current access before generating the file and My Exports checks it again at download.

**Report Subscriptions** at `/bi/subscriptions` schedules Project Status and owned saved reports. Subscribers set a daily, weekly or monthly frequency, file format, report filter and notification channel. They can edit, pause, resume or remove a subscription and review its run and delivery history. Weekly schedules run on Monday and monthly schedules run on the first day, at 08:00 IST. A five-minute shared worker advances due schedules and queues scoped exports. It checks the current account and access again before recording a ready notification. Files are retrieved after sign-in through My Exports. Email and WhatsApp use the shared gateway and the subscriber's channel preferences.

**Report Usage** at `/bi/usage` shows completed BI exports and scheduled-run outcomes for 7, 30 or 90 days. It reads the existing export audit and subscription history. Company-wide audit permission is required.
