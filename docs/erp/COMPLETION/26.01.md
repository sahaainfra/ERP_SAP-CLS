## 2. What was built

The internal `readCommissioningPunchEvidence` adapter reads explicitly linked punches through the existing QA service. It requires the commissioning flag, the company’s passed G1 and G2, the QA snag flag, and the QA record access check. It validates the requested project and any specified site, returns the live punch status, and reports linked class A punches in `OPEN` or `RECTIFIED` as blockers. QA verification and closure remove the blocker. QA continues to own the records.

A complete certificate decision requires the authoritative set of system links, mandatory check sheets, and the approval chain. Those workflows await prerequisite acceptance.
