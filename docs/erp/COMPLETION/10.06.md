## 2. What was built
- **Database** (migrations 156, 157; nothing existing altered): `proj_risk_settings`, `proj_risks`, `proj_risk_actions`, `proj_risk_triggers`, `proj_risk_contingency`, `proj_risk_issues`, `proj_risk_snapshots`; seed: flag, three navigation entries, five page-tracker rows, the library alert rule `risk.trigger_fired`.

- **Workflows**: `PROJ_RISK_CLOSE` (project manager via resolver `proj.riskpm`), `PROJ_RISK_REVIEW` (project manager, then project director), both with evidence panels.

- **API**: 44 routes under `/api/v1/proj` (`risks`, `issues`, `risk-reviews`, `risk-dashboard`, `risk-settings`), in the route policy and `openapi.yaml`.
- **Events**: `proj.risk.created`, `proj.risk.reassessed`, `proj.risk.trigger_fired`, `proj.risk.closed`, `proj.risk.contingency_allocated`, `proj.risk.drawdown_requested`, `proj.risk.review_approved`, `proj.issue.raised`, `proj.issue.resolved`.
- **Permissions**: `proj.risk.{view,create,edit,delete,submit,approve,cancel,amend,print,export}` and `proj.issue.{...}`; project manager all, project director approves, project controls manager, planner, site engineer and commercial manager raise, director views.
- **Browser**: Risk Dashboard, Risk and Opportunity Register, Risk, Issue Log, Issue; English and Hindi.
- **Docs**: ARCHITECTURE section 85, DB_CHANGES, DB_BASELINE, ADR-399 to 404, D-419 to 423, openapi.
