## 2. What was built

The internal `readDlpReleaseEvidence` adapter requires the DLP and Billing ledger flags and passed G1 and G2 for the caller’s company. It validates the input with Billing’s release preview validator, requires the `DLP_END` basis, and calls Billing’s existing permission and project checks. It returns the current retention or deposit balance, expected date and Billing checklist for the selected contract or work order.

The Billing preview covers the financial balance, date and existing open-NCR checks. Area complaint closure, expiry alerts, warranty claims, certification, and release and recovery actions await prerequisite acceptance.
