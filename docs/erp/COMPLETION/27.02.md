## 2. Delivered

**Report Builder** at `/bi/builder` uses version 1 of the Project Status dataset. Users select approved project fields, filter by lifecycle state and preview the result. They can show project counts by lifecycle or approval status across the entire visible result. The API validates field names, grouping and filters and uses bound queries from the owning register. Preview rows are paginated and sensitive fields such as contract values and salary are unavailable.

Users can save, reopen, update and delete their own reports. Company-wide holders of `ui.view.share` can share definitions with selected roles. Recipients run the saved definition with their own source permissions and scope. Save and delete use the existing audited saved-view service with version checks. CSV, XLSX and PDF exports use the selected columns and lifecycle filter. Larger exports queue in My Exports under the same permissions. Users can schedule an owned saved report from Report Subscriptions. Each run resolves the current saved fields and filter and the subscriber’s current access.
