## 2. What was built

The internal `readHandoverDocumentEvidence` adapter requires the handover and document flags, both passed company gates, and an active project and matching site within the actor’s document scope. It validates explicitly selected revisions through the document service’s client-sharing eligibility check. It returns document and revision IDs, title, revision label, file type and size. Eligibility requires a current, issued revision with a clean file suitable for external sharing and document ownership or management access.

The selected documents are evidence for a future dossier. The completed checklist, signed certificate, asset register, dossier downloads and portal sharing await prerequisite acceptance.
