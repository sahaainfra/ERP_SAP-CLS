## 2. What was built
- **Database** (migrations 82 and 83, nothing existing altered): `col_comments`, `col_mentions`, `col_reactions`, `col_trace_links`; seed: the flag, the navigation entry and tracker row of the Project Activity Feed, notifications `col.mention` and `col.reply` (English and Hindi).
- **Service** `modules/eng/collab.js`: threaded comments (reply, edit inside the window, delete with reason by a moderator, reactions, files as core files of `col_comment`); mention check against the named person's own access (BR-01); timeline per record and per project from audit, approvals, workflow, comments, documents, tasks and messages with filters; trace graph upstream and downstream with depth, status, amount, totals, restricted nodes; trace links by services, by event `col.trace.requested`, or by hand with a reason (BR-02); mentions inbox.
- **API** `/api/v1/col/*` (12 routes, all in the route policy and `openapi.yaml`): comments CRUD, reactions, `timeline`, `feed`, `trace`, `trace/links`, `mentions`.
- **Permissions**: `col.comment.moderate`, `col.trace.link`, `col.activity.view`; reading and writing a discussion needs only the right to the record. Settings are parameters `col.comment.edit_window_minutes`, `col.comment.max_length`, `col.reactions.enabled`.
- **Pages**: Discussion, Timeline and Trace tabs on the Object Page and on the sample document page; Project Activity Feed `/projects/activity` (Report); a Mentions panel on Notifications. The sample document is registered as object type `sample_doc`; its amendment writes an `AMENDS` trace link through the event `eng.sample_doc.amended`.
- Documents: ARCHITECTURE section 48, DB_CHANGES, DB_BASELINE, schema lock (14 new objects), DECISIONS ADR-211 to 215, DEFECTS D-252 to D-258, openapi, PROGRESS.csv (row 42).

## 7. How to verify manually
1. Open **Engine > Sample Documents**, open a document: the Discussion tab. Post a comment, reply, react, edit it (within 15 minutes).
2. Write `@` and a user who cannot open the record: the comment is refused with a message naming them. Mention one who can: they see it under **Notifications > Mentions**.
3. Timeline tab: filter by kind and dates. Trace tab: submit and approve a document, amend it; the amendment shows the original upstream.
4. As the project manager open **Project Activity Feed**, choose a project. As an employee: the no-permission state.
