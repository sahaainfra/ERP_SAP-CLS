## 7. How to verify manually
1. As planning open **WBS Editor**, choose a project, **Start from a template** (Building): the tree appears with codes and weights. Add a node with a weight that breaks 100 %: it is refused with the reason; **Normalise weights**.
2. Drag a node onto another (or **Move to…**), then **Undo**. Tick two nodes and **Edit 2 selected**. Open **Matrix** after adding locations.
3. **Work Packages**: group nodes for a subcontract; **Location Breakdown**: building, floor, flat; a road with chainage segments and a structure.
4. As the project manager **Baseline the WBS**: the structure locks. As planning, **Changes**: raise a change, send it; planning (another person), the project manager and the project controls manager approve in the inbox; **Versions** shows version 2 with its diff.
