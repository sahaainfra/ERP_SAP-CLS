## 4. Click-path for the reviewer
1. As ITADM: Finance → **Replay Events**; tick *Goods receipt posted* and *Vendor invoice matched*, dates 01-04-2026 to today → **Dry run**: events found, would post, would fail (with the reason of each). **Send for approval**.
2. As ACCMGR, then CFO: open the replay → **Approve**: the result appears next to the dry run (the same counts and amount).
3. As ACCMGR: **Failed Postings** → the one that could not post (SUPPLY_UNKNOWN: the vendor has no GSTIN) → close it with what was done, or put the GSTIN right and **Post again**.
4. **Sub-ledger vs GL** on the last date: every line agrees.
5. **Posting Rules** → GRN → pick a sample event → **Test**: the lines it would post. **Propose a new version** (from a date) → the CFO approves → events from that date use it.
