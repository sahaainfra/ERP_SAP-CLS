## What was built
- **Database** (migrations 266, 267): `qa_test_catalogue`, `qa_lab_equipment`, `qa_test_requests` (approval-controlled), `qa_test_results`; flag, five pages, tracker, templates. No existing table changed.
- **Results**: each value is judged against the limits of the catalogue at entry and keeps them; equipment past its calibration date is refused; the overall result follows; a concession is only for a failed result.
- **Release** (T-01): nothing changes in stock while a test waits; on approval a pass or a concession releases the lot through the receipt inspection of 16.03, a fail keeps it in the inspection stock for return to the vendor. A concession also goes to the quality control manager.
- **Compliance**: 1 test per N units or per receipt line; shortfall flagged overdue. **Calibration**: due date, certificate, daily sweep, event `qa.calibration.overdue`.
- **API**: 33 routes; **browser**: Receiving Inspections, Test Requests, Test Frequency Compliance, Lab Equipment and Calibration, Test Catalogue; English and Hindi.
