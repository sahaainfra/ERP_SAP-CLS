## 2. What was built
- **Database** (migrations 171, 172; nothing existing altered): `engg_letters`, `engg_letter_links`, `engg_time_bars`; seed: the flag, three navigation entries, four page-tracker rows, notification templates `engg.timebar.alert` and `engg.letter.overdue`; parameter `engg.time_bar_alert_days`.
- **Server** (`modules/engg/letters.js`): the letter service (register, draft, update, send for approval, issue, acknowledge, close, amend, thread, history, print on letterhead after approval, import, export, templates, search), the time-bar service (open, serve, waive, list) and the alert run (countdown at 7, 3, 1 days, lapse, overdue replies), workflow `ENGG_LETTER`, resolver `engg.letterApprover`, alert dataset `engg.time_bar`, evidence, file entity `engg_letter`; events `engg.letter.registered`, `engg.letter.issued`, `engg.letter.acknowledged`, `engg.letter.response_overdue`, `engg.timebar.opened`, `engg.timebar.alert`, `engg.timebar.served`, `engg.timebar.lapsed`.
- **API**: 25 routes under `/api/v1/engg`, in the route policy and `openapi.yaml`.
- **Permissions**: 12 keys `engg.letter.*` granted to document controller, project manager, commercial manager, project director, director, project controls manager, construction manager, site engineer, quantity surveyor, planner and design coordinator as listed in the role grants; confidential letters only to those with `view_confidential`.

- **Docs**: ARCHITECTURE section 92, DB_CHANGES, DB_BASELINE, ADR-437 to 441, D-451 to 454, openapi.
