## 2. Work delivered

The internal `readCloseoutSnapshotEvidence` adapter reads a selected Part 23.12 snapshot through Finance’s own service. It requires both feature flags and active G1 and G2 sign-offs for the actor’s company. Finance checks the actor’s company and project access and snapshot-view permission. The adapter checks that the snapshot belongs to the selected project, is approved, has a freeze timestamp and reconciles. It returns the source type and ID, project ID, document number, period and freeze timestamp.

The adapter exposes no amounts, approver identities or history. It adds no public route, navigation entry, approval action, event, or write. The frozen monthly snapshot is financial evidence for a future closeout review. Final-period selection, final-account agreement and project closure belong to the pending workflow.
