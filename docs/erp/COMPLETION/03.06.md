# Part 03.06 completion: responsive layouts, installable app and device capabilities

Status: **Ready for review, with the open items below.** Feature flag `ff.ui.p0306` (OFF by default, ON in development and test).

## What was built
- **Layouts by width** (breakpoints 360 / 768 / 1024 / 1280 / 1920): a bottom navigation on a phone (Home, My Work, Scan, Messages once that part has a page, More), a rail that opens on demand on a tablet, the full sidebar on a computer; boxes and popovers become full-screen or bottom sheets on a phone; controls are 44 px on a touch screen whatever density was chosen (ADR-135).
- **Installable app:** manifest, icons (192, 512, maskable, Apple touch) made by `scripts/build_pwa_assets.mjs`, a service worker (`src/client/sw.js` built into `dist/sw.js` with the build's id and file list), install notice (Chrome and Edge prompt; Safari steps on iPhone), update notice ("A new version is ready"), and the app shell opening with no connection. The server asks for the worker and the manifest afresh.
- **Device layer** (`src/client/platform/device`): photo compression to the company's limit with the original EXIF time and position put back (orientation set upright); position read once with accuracy, a visible notice and hints about a mocked position; a code scanner (camera, photo, typing, scanner gun) with vibration; low-bandwidth mode (data saver, slow connection or the person's choice); swipe actions and pull to refresh on lists; a queue for things waiting to be sent (filled by the offline engine of 04.15).
- **Server:** `GET /ui/device-settings` (parameters `ui.device.image_max_px`, `image_quality`, `low_bandwidth_image_px`, `low_bandwidth_quality`), `POST/GET/DELETE /ui/push-subscriptions`, `POST /ui/push/test`, `GET /ui/qr/resolve?code=` (a resolver registry each module registers its codes with); Web Push with node:crypto only (VAPID, RFC 8291 encryption), only to browser vendors' push services.
- **Pages:** Field Home (`/field`, the landing page of people whose roles are all site roles; quick actions come from the registry) and Scan (`/field/scan`).

## Click-path for a reviewer
1. Open the application on a phone-sized window (360 px) as a site engineer (role SE): it lands on Field Home with Scan and My Drafts, the online status, "Nothing is waiting to be sent" and the location notice. The bottom navigation has Home, My Work, Scan and More; More opens the full menu.
2. Open Scan, type a sample request number (as a project manager the number of a submitted request): you are taken to the record; a wrong number says "Nothing found" with its correlation ID; press "Scan with the camera" and the camera view opens.
3. As a system administrator open Design System, Form Components: use "Use my position" (the notice sits under the buttons; accuracy is shown, a weak fix says to move into the open); choose a large photo: it is made smaller, and the line under it shows the time and position it carries.
4. Account menu: Low-bandwidth mode, notifications on this device with a test message, language, theme.
5. In Chrome, DevTools, Application, Manifest and Service workers show an installable app; switch the network to Offline and reload: the app and Home still open. Deploying a new build shows "A new version is ready".

## Defects found on the way (fixed)
- A form's sticky action bar covered the phone's bottom navigation, so "More" could not be pressed; the shell's layers now use the token z-index scale and the bar rests on the navigation.
- The service worker's first version lost its offline copies on every page start (a clean-up ran in each page load) and could not use its cached files because the server varies on Origin; both fixed (found by the offline test).
- Parameter values changed on the parameters page were not seen by modules that cache their own store (the approval clock of 03.04 as well): they now read afresh and by the Indian business date, not the UTC date (D-150).
- Specs that name company ids fixed in advance collided with companies the new specs create (the monitor spec); it now sends the settings' version when settings exist (D-142 remains open for the others).
