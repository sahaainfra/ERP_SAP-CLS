Part: 03.03 Data Table & List Report Component    Date: 2026-11-01    Build/commit: on top of ff709a0 with parts 03.01 and 03.02 (working tree, uncommitted)

## 1. Discovery summary
There was no list component: every register built its own table, search and selects, paged with previous/next, and exported CSV in the browser by fetching every page. The users list had per-browser saved views and column choices; `ui_user_preferences.table_settings_json` (03.01) was stored but unread (D-117); the export guard of 02.07 existed. No XLSX or PDF library was installed. Decision per requirement: `docs/erp/DISCOVERY/03.03.md`. Departures: XLSX and PDF are written by small built-in writers, so no package was added (D-126); a finished background export is announced by My Exports and an event until notifications exist (D-125); only the reference register is migrated so far (D-124).

## 2. What was built
- **List Report contract** (`platform/list`): a register declares its columns once (`defineList`: SQL, type, label, sortable, filterable, total). The same definition validates the request (`q`, `sort=-a,b`, `page`, `pageSize` 25/50/100/200, `filter[key]=v` and `filter[key][op]=v` with eq, ne, in, gte, lte, between, contains, empty, notempty per column type), binds every value, and returns the page, the total count and the totals of the numeric columns over the whole filtered set (FR-01, FR-02, FR-09, BR-01).
- **List Report component** (`src/client/platform/list/ListReport.jsx`): search; status chips, "My records" and date presets (today, this and last month, this quarter, this and last financial year); an advanced filter builder (field, operator, value) with removable filter chips; saved views (personal, or shared with roles by those with `ui.view.share`; open with a default view); a column chooser (show, hide, move left/right) and column widths (drag the header edge or use the arrow keys), kept per person in table settings; sticky header, frozen first column, sticky totals row, windowed rows for pages over 60 rows; selection with the page's bulk actions, a confirmation and a result summary naming each failure; server exports; row links (open in a new tab with a middle click) and a row actions menu; cards with key fields below 768 px, scrolling only inside the table; skeletons and the empty, error (with correlation ID) and no-permission states. Its menus close on a click outside or Escape.
- **Exports** (`platform/export`, `modules/ui/lists.js`): `GET <register>/export?format=xlsx|csv|pdf&<the screen's query>` writes the same rows with the same masks (BR-02); CSV with a BOM and quoting, XLSX with numbers as numbers and money in Indian grouping, PDF in landscape pages; formula-looking text made inert; a generated-by/at and filters footer; every export audited through the 02.07 export guard. Above `core.export.max_rows` a job (`ui.export`) writes the file as the requester (their scope and masks) and keeps it 7 days under My Exports (daily purge `ui.export_purge`; event `ui.export.completed`).
- **Saved views** (`ui_saved_views`, `/api/v1/ui/saved-views`): personal views stay with their owner; shared views reach their target roles or projects only; one default per person and list; optimistic version (409); names unique per person and list; every change audited; event `ui.saved_view.changed`.
- **Masks**: the request total is a commercial field (`ui_sample_request.total`): shown to PM, PD, PCMGR, ACCMGR, CFO, DIR and SUPADM, masked ("•••") for the others, including the system administrator, in rows, the totals row and every export; a masked column cannot be sorted or filtered (ADR-120).
- **Reference register migrated** (AC-01): Sample Material Requests now runs on the component and the contract, with bulk submit and cancel (`POST /ui/sample-requests/bulk`, each request on its own, results named).
- **Pages**: Sample Material Requests (the reference List Report), List Report documentation (`/admin/design-system/lists`: properties, the server API, the contract and the live column description), My Exports (`/account/exports`).
- **Permission** `ui.view.share` for SYSADM, PM, PD, PCMGR, ACCMGR, CFO, HRMGR, DIR (and SUPADM).
- Docs: `ARCHITECTURE.md` section 27, `DECISIONS.md` ADR-119 to ADR-122, `DEFECTS.md` D-124 to D-127 (D-117 closed for lists on the component), `DB_CHANGES.md`, `DB_BASELINE.md`, `openapi.yaml`, route policy (314 routes), `schema/baseline.json` re-locked (324 objects; the 316 existing unchanged).
