## 7. How to verify manually
1. As ACCMGR: Finance → Capitalise, Depreciate & FA Reports → **1 · Capitalise**: the AP bill of the excavator, class *Earth-moving*, → **Save and send to the CFO**. As CFO: the asset → **Approve**: in use.
2. **2 · Depreciation run**: last month → the preview by class → **Post the depreciation**; the same month again is refused.
3. Asset Register → the asset: the schedule (posted and projected). **Transfer** to another project. **Dispose**: sale, proceeds, buyer, HSN → the gain or loss; CFO approves (and a director above ₹10 lakh); Receivables shows the draft to invoice.
4. CWIP: tick the bills booked to 115001 → **Gather into a CWIP** → capitalise it.
5. On the phone as PM: Asset Register → **Physical verification** → start for the project → type or scan `FA:<asset>` → **Close**: missing assets reported.
6. **3 · Fixed asset schedule** and **4 · Tax depreciation by block** for 2026-27.
