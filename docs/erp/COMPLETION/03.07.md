# Part 03.07 completion: dashboard and widget framework, My Work

Status: **Ready for review, with the open items below.** Feature flag `ff.ui.p0307` (OFF by default, ON in development and test).

## What was built
- **Widget registry and one data endpoint.** `ui_widgets` says what each of 23 widgets is (owning module, type, permission key, default size, refresh seconds, drill route); the owning module registers the provider in code with `platform/widgets`. `GET /ui/widgets/:code/data` checks the widget's permission, reads the same tables as the list behind it inside the person's data scope with bound SQL parameters, masks values with the list's own mask rule, and returns an empty result (never a sample) when there is nothing.
- **Widgets:** KPI with trend against the period before, target and red/amber/green; bar, stacked bar, line, area (the S-curve), donut, gauge (approvals decided in time against `ui.widget.timeliness_target`), heat map and Gantt strip; top-N table; alerts (overdue requests); lists (my approvals, tasks, projects, mentions); site positions; month calendar; quick actions; notice.
- **Dashboards:** `ui_dashboards` holds the two standard dashboards (My Work, Requests Overview), the default of a role and each person's own copy. A person sees their own copy, else the default of their role, else the standard layout; widgets their role may not use are left out and counted. A person's own layout is saved at once (audited, version-checked across devices) and "Reset" gives it up. The default of a role is a change request (`ui_dashboard_change`, another system administrator approves, reason kept, version check when approved, audit entry and event `ui.dashboard.changed`).
- **Client:** a chart library of our own in SVG (`src/client/platform/charts`: bar, stacked, line, area, donut, gauge, heat map, Gantt; the colours are the design tokens so both themes work; tooltip on hover and focus; legend; the same figures as a table; CSV that cannot run as a formula; PNG). The dashboard framework (`src/client/platform/dashboard`): global filter bar (project, site, period with this month, quarter and this and last financial year presets), a frame for every widget with loading, empty, error (correlation ID, retry) and no-permission states, "Updated" time, refresh button and refresh by interval, a twelve-column grid (one column on a phone, six on a tablet), and Customise (drag-and-drop or move, narrower, wider, shorter, taller and remove buttons, add from the catalogue, widget settings).
- **Drill-down:** the address of a figure, bar or slice carries the list's filters; the List Report reads them from the address (`filtersFromSearch`), so the list opens with the rows and count the widget counted.
- **Pages:** My Work (`/work`, first in the My Work group and behind the phone's "My Work"), Requests Overview (`/admin/sample-requests/overview`) and the Dashboard Designer (`/admin/dashboards`, `ui.dashboard.manage`: pick a dashboard and role, arrange, preview with your own data, export and import the layout, ask for the change with a reason, the waiting requests with approve and reject, and the history of the role).

## Click-path for a reviewer
1. Sign in (or use the development identity) as a project manager and open **My Work**: figures come from the register, tasks and approvals say they are empty, each box says when it was read; use the Period list (this and last financial year) and Project.
2. Click the Draft slice of "Requests by status": the Sample Material Requests list opens filtered to drafts and its total equals the slice.
3. Choose **Customise**: move a box with the buttons or drag its title; remove one; add a Notice and write its text; **Save my layout**. Open the application in another browser as the same user: the same arrangement. **Reset to default** brings back the standard layout.
4. As a system administrator open **Dashboard Designer**, role SE: remove a widget, add a Notice, give a reason, **Request this default**. As another system administrator open the same page and approve it. A new site engineer opening My Work now sees that layout ("the default of your role"); a project manager still sees the standard one.
5. On **Requests Overview**: open "View as table" under a chart, press CSV and PNG, and switch the theme to dark.
